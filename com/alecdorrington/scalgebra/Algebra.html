Algebra

com.alecdorrington.scalgebra.Algebra
See theAlgebra companion object
trait Algebra[X]

The ultimate base trait of all Scalgebra type classes.

This exists as a work-around for some idiosyncrasies of Scala's context parameter resolution.

In particular, all given instances are provided in Algebra's companion object, which allows them to always be found, even when not imported.
